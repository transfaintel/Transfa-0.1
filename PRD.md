Transfa is a fintech mobile application focused on NGN wallet infrastructure with support for local transfers and USD/stablecoin-enabled international transfer flows.

Core Features:
- User authentication
- NGN wallet balance
- Dedicated virtual account funding
- NGN bank transfers
- USD/stablecoin transfer flow
- Transaction history
- Notifications
- Profile/settings

Users only hold NGN wallet balances in-app.

When users initiate USD transfers:
- backend calculates FX conversion
- NGN wallet is debited
- backend routes through stablecoin/international payout infrastructure
- recipient receives external payout

Primary payment infrastructure:
- Flutterwave Dedicated Virtual Account
- Flutterwave transfers
- stablecoin routing providers

Design Style:
- modern fintech
- clean premium UI
- rounded cards
- minimalist spacing
- smooth animations
